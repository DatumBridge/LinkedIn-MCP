# Use Cases — LinkedIn MCP

| Use case | Tools |
|----------|-------|
| Resolve who is authenticated | `get_me` |
| Announce a product update with article link | `create_post` |
| Share a generated image + caption | `create_image_post` |
| Inspect a created share | `get_post` |
| Remove a mistaken share | `delete_post` |

Out of scope: company page campaigns, InMail outreach, competitor scraping.
